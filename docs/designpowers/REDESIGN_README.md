# Redesign Package: The Gatefold Studio

This folder contains the complete design blueprint for the Toledo Technologies "High-Fidelity" transformation.

## Core Documentation

1.  **[Design Strategy](strategy/gatefold-studio-strategy.md):** The core narrative and mechanical principles (Physicality, Analog High-Def, Technical Novels).
2.  **[Design Handoff](handoff/gatefold-studio-handoff.md):** Final technical specifications for interactions, typography, and responsive art direction.
3.  **[Inclusive Personas](personas/2026-05-09-gatefold-studio-personas.md):** The decision-makers we build for.

## Implementation Highlights

- **Physicality:** The site uses a "Gatefold" entry. Desktop uses a 3D hinge reveal; Mobile uses a tap-to-reveal "Record Release" metaphor.
- **Narrative-First:** Sub-pages are treated as "Technical Novels" using the `novel` and `spread` CSS patterns.
- **Responsive Art Direction:** Heroes are art-directed (Microphone for desktop, CRT Workstation for mobile) to maximize visual impact per device.
