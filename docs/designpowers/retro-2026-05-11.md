# Design Retrospective: Website Content Overhaul (5-Microsite Pivot)

**Date:** 2026-05-11
**Duration:** 1 session
**Mode:** mixed
**Agents used:** 5 of 9

## Summary

The project successfully pivoted the Toledo Technologies website into a 5-microsite ecosystem. We replaced generic placeholder content with high-fidelity, direct copy that adheres to the "Gatefold" and "Novel" principles. The process was efficient, moving from discovery to implementation in a single focused flow.

## What Worked

| Decision                   | Why It Worked                                                    | Evidence                                                      |
| -------------------------- | ---------------------------------------------------------------- | ------------------------------------------------------------- |
| 5-Microsite Routing        | Clarifies the studio's structure and specialized offerings.      | Strategy approved; cards implemented in /services.            |
| "Direct" Voice             | Aligns with the Project Identity of being blunt and senior-only. | Critique pass; user approval on "grave intention."            |
| /care & /discovery Pillars | Centralizes shared services and paid front doors.                | Implementation verified; correctly linked from Home/Services. |
| Vinyl Conceit (A2, B6-B8)  | Reinforces the tactile, physical identity of the project.        | Specificity Test passed in critique.                          |

## What Didn't Work

| Decision               | What Went Wrong                                                     | Root Cause                                                   | Fix Rounds        |
| ---------------------- | ------------------------------------------------------------------- | ------------------------------------------------------------ | ----------------- |
| Standard Form Styling  | Feels a bit too "default web" for a high-fidelity physical conceit. | Balancing functional intake with aesthetic physicality.      | 0 (Accepted Debt) |
| Manual Pricing Updates | Potential for drift if PRICING.md isn't synced.                     | Lack of automated single-source-of-truth for pricing values. | 0 (Process Note)  |

## Process Assessment

- **Pipeline efficiency:** 5 agents used (discovery, strategist, lead, builder, critic). The flow was linear and fast.
- **Handoff quality:** High. Handoffs correctly preserved context about "grave intention" and "taste standards."
- **User engagement:** The user provided high-signal directives ("apply the real shit," "grave intention and art") which steered the builder and critic effectively.

## Design Debt

- **Minor:** "Physicalize" the intake forms on /care, /discovery, and /partner (e.g., typewriter style).
- **Note:** Active monitoring of subdomain SSLs and redirect logic for the 5 microsites.

## Taste Evolution

- **Strong Opinion Confirmed:** "Directness is the product." The user responds best to blunt, high-stakes communication over "polished" agency speak.
- **Soft Pattern Confirmed:** Physical analogies (Vinyl, Liner Notes) are the strongest differentiating factor for this project's UI and Copy.
- **New Anti-Pattern:** Avoid "agency theatre" at all costs—no fluff, no jargon, no standard 3-column icon grids.

## Carry Forward

- **For next project:** Always start with the "Directness" lens. Ask: "Is this too polished? Is it blunt enough?"
- **For design-builder:** When building forms for this project, look for ways to make them feel like physical paper/typewriter output.
- **For design-critic:** The "Swap Test" (can we swap in a competitor?) is the most effective tool for verifying Toledo copy.
