# Project Taste Brief — Toledo Technologies

> Synthesized from taste audit findings, 2026-04-04. The site's own voice
> (especially the nonprofit page, FAQ answers, and "Fix My Broken Thing"
> CTA) told us who this project is.

## Project Identity

### This project believes:
Most development projects end in frustration because the people doing
the work optimize for looking professional instead of being honest.
Toledo Technologies believes directness is the product. The code should
be clean, the communication should be blunt, and the client should never
have to wonder what's happening. The nonprofit arm (Daedalus Landed)
goes further: the basics of being human shouldn't be paywalled.

### This project is for:
People who have been burned. Founders who hired a dev shop and got
excuses instead of code. Teams whose last contractor disappeared.
Nonprofits told "you can't afford good tech." They are skeptical of
promises, allergic to jargon, and will evaluate Toledo by what it
ships — not what it claims.

### This project should feel like:
- A well-maintained CLI tool: precise, responsive, zero decoration,
  respects your time
- A mechanic's shop that's clean but not pretty: tools organized,
  grease on the floor, work getting done
- The senior developer on the team who doesn't talk much but whose
  code never breaks and whose PRs are always clear

### This project should NEVER feel like:
- A SaaS landing page fishing for signups with gradient text and
  animated illustrations
- An agency that leads with "our process" and "our values" before
  showing any actual work
- A startup that says "empower" and "revolutionize" because it
  hasn't figured out what it actually does yet
- A treatment center or wellness app (for the nonprofit arm)

### The one word that MUST describe this project:
DIRECT

### The one word that must NEVER describe this project:
POLISHED

## Anti-References (projects whose DNA we reject):
- Toptal / Gun.io — marketplace energy, generic "top talent" promises
- Accenture / Deloitte Digital — process theater, deliverable inflation
- Any Tailwind template site with Inter font and indigo gradients

## Unexpected References (outside this space):
- A well-organized workshop: tools have places, nothing is decorative,
  you can tell someone works here
- Haynes repair manuals: dense, practical, assumes you're competent,
  every diagram serves a purpose
- The Criterion Collection: curated, opinionated, treats its audience
  as intelligent — never dumbs down

## Taste Constraints (rules we won't break):
- Typography signals code. Monospace headings are identity, not decoration.
- Warm accent (forge orange) only surfaces on interaction — steel that
  glows when you touch it. Never used decoratively.
- Copy states what the thing DOES. No hedging ("might," "could
  potentially," "helps you"). No negation-based positioning ("no fluff"
  used once is a statement; repeated, it's a crutch).
- The 404 page is the taste benchmark. Every new page should be measured
  against it: does structure, copy, and visual treatment all reinforce
  the same specific identity?
- Elimination before addition. When in doubt, delete.
